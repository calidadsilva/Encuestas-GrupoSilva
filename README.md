# 📊 Encuestas de Satisfacción Grupo Silva

Centro centralizado de encuestas de satisfacción para Grupo Silva.

## 🌐 Encuestas Disponibles

1. **Encuesta Entrega 0km** (`encuesta-entrega-0km.html`)
   - Satisfacción de clientes en entrega de motos 0km
   - Preguntas sobre experiencia de compra y entrega

2. **Encuesta Sucursal Colón** (`encuesta-sucursal-colon.html`)
   - Encuesta general de satisfacción de sucursal
   - Evaluación de atención y servicios

3. **Encuesta Pintura y Construcción** (`encuesta-pintura-construccion.html`)
   - Encuesta anónima para sucursales de pintura y construcción
   - Preguntas sobre experiencia de compra

4. **Registro de Política** (`registro-politica.html`)
   - Registro de política de recepción y aprovisionamiento
   - Documentación de procesos

## 🚀 Cómo Usar

- Accede a cualquier encuesta desde el índice principal
- Completa el formulario desde tu navegador
- Los datos se guardan automáticamente
- Comparte los QR en las sucursales para encuestas en sitio
